# test.project

A Node.js workspace intended for a **TypeScript** app built with **Next.js** (App Router).

## Current status

The repo is a starter. `package.json` currently includes:

- Node.js (CommonJS)
- [dotenv](https://www.npmjs.com/package/dotenv) for environment variables

Next.js and TypeScript are the target stack; they are not installed yet.

## Requirements

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm (comes with Node.js)

## Setup

```bash
npm install
```

Copy environment variables into a `.env` file in the project root. `dotenv` loads them at runtime.
